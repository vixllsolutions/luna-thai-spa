LUNE THAI SPA WEBSITE BUNDLE

CONTENTS
- index.html: website page
- styles.css: responsive styling, layout and animations
- script.js: mobile navigation, treatment filtering/search, gallery lightbox and reveal effects
- assets/: all supplied spa photos and screenshot references, copied directly into this one folder

HOW TO PREVIEW
Open index.html in a modern browser. An internet connection is recommended for the hosted Google Fonts and the WhatsApp / Google Maps links; the page layout, photos and interactions are bundled locally.

HOW TO DEPLOY
Upload index.html, styles.css, script.js and the complete assets folder to the root of a static host such as GitHub Pages, Netlify or your web hosting public directory. Keep the assets folder name and file names unchanged so all image paths work.
